# Pin Map Maker

Open a map image or PDF, drop numbered pins, write text for each one, and save a phone-ready PDF where every pin opens its own page.

Everything runs in the browser. Maps, pins and text are never uploaded; they stay on the person's device and inside the PDF they save.
